DSH onyour iPhone.

Pair Narwal with DeepSeek Harness over Wi-Fi and pick up your DSH sessions on your iPhone.

Install

From desktop to iPhone

  1. Install the plugin

    In DSH, open Settings → Plugins, install narwal-dsh-remote, and restart DSH. For a CLI-managed profile, use this command.

    dsh plugin --profile <your-profile> add narwal-dsh-remote

  2. Create a pairing token

    On the desktop, open Settings → Narwal. Create a pairing token and open its QR code.

  3. Pair your iPhone

    On the same Wi-Fi, open Narwal and scan the QR code or paste the pairing link. Revoke the token in DSH to disconnect the device.
