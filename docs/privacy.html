Privacy Policy

Public draft for review.

Scope

This draft covers this website and Narwal’s connection to DeepSeek Harness (DSH).

Direct connections, credentials, and logs

In direct mode, the Narwal app and DSH plugin exchange requested session content, commands, and responses on your local network. The desktop plugin stores pairing tokens. Pairing QR codes and links contain credentials. The plugin also logs some administrative events locally, which may include device labels, token identifiers, and timestamps.

Optional relay and external services

If you enable a relay, connection traffic passes through the relay you configure. Model providers and other services used by DSH handle data under their own policies.

Website and feedback

This site loads no project analytics scripts or external fonts. GitHub Pages hosts the site and GitHub may process access data such as IP addresses. See the GitHub Privacy Statement. GitHub Issues are public.

Managing access and contacting us

You can revoke pairing tokens in DSH and remove saved connections in the app. Use GitHub Issues to ask how to submit a private report. Keep tokens, pairing links, logs, and session content out of public posts.
