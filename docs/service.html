Service Statement

Public draft for review.

Scope

Narwal is a third-party project for connecting to DeepSeek Harness (DSH). The plugin runs in your DSH instance and lets the paired Narwal app use features exposed by that instance.

Access and credentials

Only connect to devices and DSH instances you have permission to use. Keep pairing links and QR codes private. Revoke a token in DSH if it is exposed or the device no longer needs access.

Compatibility and availability

The plugin depends on DSH, the Narwal app, your devices, and your network. Optional relays and other third-party services are managed by their providers.

License and feedback

The plugin code in this repository is available under the MIT license. Use GitHub Issues for general questions and feedback. Keep sensitive information out of public posts.
