服务声明

公开草稿，供审阅。

服务范围

Narwal 是用于连接 DeepSeek Harness（DSH）的第三方项目。插件在你的 DSH 实例中运行，配对后可通过 Narwal App 访问该实例提供的功能。

访问与凭据

请仅连接有权使用的设备与 DSH 实例。请妥善保管配对链接和二维码。若凭据泄露或不再需要某台设备的访问权限，请在 DSH 中撤销对应令牌。

兼容性与可用性

插件能否正常运行取决于 DSH、Narwal App、设备和网络环境。可选中继和其他第三方服务由相应提供方管理。

许可与反馈

本仓库的插件代码适用 MIT 许可证。可通过 GitHub Issues 提交普通问题和反馈，请勿公开敏感信息。
