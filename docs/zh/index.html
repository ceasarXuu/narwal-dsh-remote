桌面 DSH，手机接着用

Narwal 插件将 iPhone 上的 Narwal App 与桌面端的 DeepSeek Harness 连接起来。通过同一 Wi-Fi 配对，在手机上继续使用 DSH 会话。

安装

从桌面到手机

  1. 安装插件

    在 DSH 的「设置 → 插件」中搜索并安装 narwal-dsh-remote，然后重启 DSH。如果使用命令行管理独立的 profile，可用以下命令。

    dsh plugin --profile <your-profile> add narwal-dsh-remote

  2. 创建配对令牌

    在桌面端打开「设置 → Narwal」，创建配对令牌并打开二维码。

  3. 用 iPhone 配对

    在同一 Wi-Fi 下，在 Narwal App 中扫描二维码或粘贴配对链接。可在 DSH 中撤销令牌来断开设备。
