适用范围

本草稿涵盖本站和 Narwal 连接 DeepSeek Harness（DSH）的功能。

直连、凭据与日志

直连模式下，Narwal App 在本地网络上与 DSH 插件交换所请求的会话内容、指令和结果。插件在桌面端保存配对令牌。配对二维码和链接包含连接凭据。插件也会为部分管理操作记录本地日志，其中可能包含设备标签、令牌标识及时间。

可选中继与外部服务

如果启用中继，连接流量会经过所配置的中继服务。DSH 调用的模型和其他服务按各自的政策处理数据。

本站与反馈渠道

本站不加载项目自己的分析脚本或外部字体。本站由 GitHub Pages 托管，GitHub 可能处理访问者的 IP 地址等访问数据。请参阅 GitHub 隐私声明。GitHub Issues 公开可见。

管理访问与联系

可在 DSH 设置中撤销配对令牌，并在 App 中移除已保存的连接。可通过 GitHub Issues 询问如何提交私密报告，请勿贴出令牌、配对链接、日志或会话内容。
